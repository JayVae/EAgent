DeepSeek EAgent Web

0配置、0门槛、0tokens。基于 deepseek 网页版制作的简易 Agent，
不需要 API Key，实现 tokens 自由。

免 API Key tokens 自由 Edge 浏览器 Win10 / 11 E语言编写
下载 EAgentWeb.exe

环境要求

  • Edge 浏览器（电脑自带）
  • Win10 / 11 更早的 win 版本我没测试过，我不知道喵。

起源 —— 为了省钱

  • 市面上常见的 Agent，它们的功能都比我这个项目强大 100 倍！但它们都需要 ApiKey、都需要花钱买 tokens。
  • 但我是个穷 B，只能用免费的 deepseek 网页版。我又不是搞什么企业级 Agent 工作任务，难道还要花几毛钱的 tokens 跟 AI 说“你好”、花几块钱让 AI 帮我写个文章？哎呀用网页端得了。
  • 但是，网页 AI 无法直接编辑我的电脑文件。开发中只能让 AI 生成代码，然后复制粘贴。那我直接让 AI 生成 PowerShell 代码，直接执行，把结果扔给它，不就好了吗？卧槽对啊，于是就有了这个项目：自动复制粘贴、自动执行 PowerShell 代码、实现 token 自由！

快速使用

  1. 下载文件：GitHub Releases
  2. 解压、运行 EAgentWeb.exe。
  3. 进入程序，点击 选择工作目录 按钮，选择一个目录。
  4. 然后会自动打开 Edge 浏览器，请自行登录后，才能进行下一步操作。
  5. 点击 开始新对话。等待 AI 分析提示词……
  6. 到你回复 AI 了！使用工具发送信息，而不是用网页版发送信息。网页版的唯一作用就是给你看的，而不是发消息的。

实现逻辑

  • 本项目不是反代，没有逆向 deepseek 网页。
  • 用人话来讲，底层逻辑就是：通过 Edge 浏览器开发者模式，调用复制粘贴，实现 工具 - 模型 交互，完成 Agent 循环。

AI 对本项目原理的总结

用 PowerShell 连接 Chrome/Edge 的远程调试端口，
通过 CDP WebSocket 在真实 DeepSeek 页面里执行 JavaScript，
模拟输入、上传文件、点击发送，并轮询 DOM 判断助手回复是否稳定，
最后返回助手回复信息。

适用场景

个人工具、学习交流、拿来玩、协助开发、节省在网页端复制粘贴 AI 代码的流程……
